# MindMend Guardian 🧠🛡️

**Full youth safety AI ecosystem — Michigan MindMend 2025**

Gentle always-on voice companion + real-time child protection backend.

- **Guardian Voice AI**: <1W ultra-low-power chill mode → wakes on "hey mindmend" → natural conversation with TTS
- **Luna Safety Core**: Threat/grooming detection, geofencing, async parent alerts

Offline-first, private, compassionate. Built to listen when needed and protect always.

## Features
- Ultra-efficient Silero VAD + whisper.cpp wake
- Optional local LLM (llama.cpp GPU offload)
- Flask backend with spaCy sentiment + tests
- MIT License — open for collaboration

## Files
- guardian/mindmend_guardian.py → full voice script
- luna/luna_safety_core.py → safety backend
- Demo folder coming soon

Protecting the future, one voice at a time.
