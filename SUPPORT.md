# Support

Thanks for your interest in MindMend Guardian.

## Where to get help

| Need | Channel |
| ---- | ------- |
| Bug reports | [GitHub Issues](https://github.com/MiMindMendinc/mindmend-guardian/issues/new/choose) |
| Feature ideas | [Feature request template](https://github.com/MiMindMendinc/mindmend-guardian/issues/new/choose) |
| Security concerns | [`SECURITY.md`](SECURITY.md) — do not open public issues |
| Contribution questions | [`CONTRIBUTING.md`](CONTRIBUTING.md) |
| Setup and installation | [`SETUP.md`](SETUP.md) and [`README.md`](README.md) |

## Response expectations

This is a volunteer-maintained open source prototype. Maintainers review issues
and pull requests as time allows. For security reports, see the response targets
in [`SECURITY.md`](SECURITY.md).

## Crisis boundary

MindMend Guardian is not a crisis service. If someone may be in immediate
danger, contact local emergency services. In the United States, call or text
**988** for the Suicide & Crisis Lifeline.
